## 12기 독서 · 일제강점기 시

### 1회차 윤동주 (2026-11-25)
`12기-독서/일제강점기-시/1회차-윤동주/`

「나는 얼마큼 작으냐 — 부끄러움을 쓴 시인들」, 15장.

1. 여는 시: 김수영 「어느 날 고궁을 나오면서」(1965)
2. 「100일의 거짓말」 포스터로 시대 들어가기
3. 윤동주: 서시 → 자화상 → 쉽게 씌어진 시
4. 함께 보기 · 핵심 토론 · 글쓰기

- `project/deck.json`: 슬라이드 순서
- `project/deck.css`: 공통 스타일
- `project/slides/*.html`: 슬라이드 한 장씩 (`<aside>`는 발표자 노트)
- `images/`: 시인 사진, 포스터

윤동주 사진은 퍼블릭 도메인(위키미디어 공용)이다.
